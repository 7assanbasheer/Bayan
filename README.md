# موقع مكتب بيان للخدمات القانونية واستشاري العقود الاحترافية
## Bayan Office | Professional Contracts Consultant & Legal Services

موقع إلكتروني احترافي وفاخر لمكتب **بيان** للخدمات القانونية واستشاري العقود الاحترافية، بقيادة **بيان الجعفر** (حاصلة على ماجستير في القانون Master of Law)، يبرز خبرتها التي تتجاوز 5 سنوات وتجربتها العملية في أكثر من 50 عقدًا تجاريًا ومصرفيًا، بالإضافة إلى قضايا الأحوال الشخصية (الطلاق والنفقة) ونظام العمل السعودي في المنطقة الشرقية، المملكة العربية السعودية.

---

### 🌟 مميزات المشروع
1. **تصميم فاخر وعصري (Boutique Agency Standard)**:
   - لوحة ألوان راقية تعتمد على الكحلي الداكن (`#142536`)، الذهبي الهادئ (`#B79A62`)، الأبيض العاجي (`#F8F6F1`)، والرمادي للنصوص الثانوية (`#717780`).
   - شعار نصي وأيقونة مونوغرام هندسية فاخرة تجمع بين الحرفين BA والاسم العربي "بيان الجعفر".
   - مساحات بيضاء واسعة، حدود ذهبية ناعمة، وتأثيرات بصرية راقية مستوحاة من الأنماط الهندسية المعمارية وتفاصيل العقود.

2. **ثنائي اللغة بالكامل (العربية والإنجليزية)**:
   - دعم كامل للغة العربية (RTL) مع خطوط `Alexandria` و `IBM Plex Sans Arabic`.
   - دعم كامل للغة الإنجليزية (LTR) مع خط `Inter`.
   - تبديل فوري للغة بنقرة واحدة مع حفظ تفضيل المستخدم في المتصفح.

3. **هيكل الصفحات والأقسام**:
   - **الرئيسية (Home)**:
     - Hero Section فاخر بالرسالة المعتمدة: "حلول قانونية وعقود تُبنى على الوضوح والثقة".
     - قسم المؤشرات الثلاثة: (+5 سنوات خبرة، +50 عقدًا، المنطقة الشرقية).
     - نبذة عن بيان وفلسفة العمل القائمة على الوضوح وتجنب النزاعات.
     - شبكة الخدمات الست مع نافذة تفاعلية للشروط والحالات المناسبة.
     - قسم الخبرات المهنية في القطاع المصرفي والشراكات وسياق بيئات الأعمال (مثل Elm و Tamara).
     - قسم منهجية العمل من 4 مراحل.
     - قسم دعوة للتواصل عبر الواتساب والبريد.
     - الأسئلة الشائعة FAQ مع قائمة أكورديون تفاعلية.
     - نموذج التواصل التفاعلي المكتمل.
   - **صفحة نبذة عن بيان (`/about`)**: سيرة مهنية رصينة وإطار مخصص للصورة الشخصية ومؤهل Master of Law.
   - **صفحة الخدمات (`/services`)**: تفصيل شامل للخدمات، الحالات المناسبة، والمعلومات المطلوبة قبل التواصل مع فلاتر سريعة.
   - **صفحة الخبرات المهنية (`/experience`)**: إبراز خبرات البنوك، الشراكات المؤسسية، والعقود التجارية.
   - **صفحة الأسئلة الشائعة (`/faq`)**: بحث تفاعلي وأسئلة تفصيلية قابلة للتوسيع.
   - **صفحة التواصل (`/contact`)**: نموذج تواصل متقدم مع قنوات مباشرة للواتساب والاتصال والبريد.
   - **صفحة سياسة الخصوصية (`/privacy`)**: متوافقة مع نظام حماية البيانات الشخصية السعودي (PDPL).
   - **صفحة الشروط والأحكام والتنويه القانوني (`/terms`)**: توضيح طبيعة المحتوى وحدود المسؤولية.

4. **تواصل آمن وشفاف**:
   - نموذج تواصل مع تحقق ذكي من الحقول (Validation).
   - توضيح أمني بعدم إرسال وثائق سرية أو أرقام هوية في النماذج العامة.
   - مسار API حقيقي في الخادم (`/api/contact`) مهيأ للربط مع مزودات البريد (Resend / SMTP).
   - خيارات الإرسال الفوري المباشر عبر تطبيق WhatsApp بنصوص مجهزة تلقائيًا.

5. **تحسين محركات البحث SEO**:
   - بيانات منظمة بصيغة Schema.org JSON-LD للتعريف بالخبيرة ومؤهلها دون ادعاءات غير موثقة.
   - عناوين ووصف ميتا فريد لكل صفحة باللغتين.
   - توليد تلقائي لخريطة الموقع `sitemap.xml` وملف `robots.txt`.

### 🚀 تعليمات التشغيل المحلي (Getting Started)

1. **تثبيت الحزم (إذا لم تكن مثبتة مسبقًا)**:
   ```bash
   npm install
   ```

2. **تشغيل بيئة التطوير**:
   ```bash
   npm run dev
   ```
   افتح المتصفح على: `http://localhost:3000`

3. **بناء النسخة الإنتاجية (Production Build)**:
   ```bash
   npm run build
   npm run start
   ```

---

### ⚙️ إعداد متغيرات البيئة (Environment Variables)

لربط نموذج التواصل بخدمة إرسال البريد المباشر إلى `BAYAN@BAYAN.LAW.SA`، قم بنسخ الملف `.env.example` إلى `.env.local` وضع مفاتيحك:

```env
# مثال باستخدام Resend:
RESEND_API_KEY=re_your_api_key_here
EMAIL_FROM=notifications@bayan.law.sa
EMAIL_TO=BAYAN@BAYAN.LAW.SA
```
